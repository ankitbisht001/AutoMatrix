# AutoMatrix
A full-stack car comparison web app built with React, Spring Boot, and MySQL, featuring JWT authentication, reviews, and an admin panel for car management.
AutoMatrix is a full-stack web app that lets users compare cars side-by-side by engine, dimensions, and features. It includes user authentication, review submission, saved comparisons. Also an admin panel to manage car data.

🔧 Tech Stack Frontend: React.js, Tailwind CSS

Backend: Spring Boot, Java, JWT, MySQL

Database: MySQL with Hibernate (JPA)

✅ Key Features Compare two cars with detailed specs

User signup/login (JWT-secured)

Ratings, reviews, and saved comparisons

Admin panel to add, edit, delete car data
